# Caveduck編輯器

給鴨答（[caveduck.io](https://caveduck.io/)）創作者用的 Tampermonkey 腳本。把 Google Sheet 裡整理好的內容複製起來，貼進面板按一下就填進網站；也能把網站上現有的內容匯出，貼回 Google Sheet 修改。

目前版本：1.7　｜　作者 [@lyre273](https://lyre-projects.pages.dev/)

作者網站：<https://lyre-projects.pages.dev/>（問題回報與留言也在這裡）

| 可以處理的內容 | 在哪裡使用 |
|---|---|
| 小工具的狀態值與文字 | 小工具編輯頁 |
| 小工具的多語翻譯 | 小工具編輯頁的「管理翻譯」視窗 |
| 關鍵字書（Lorebook）的基礎關鍵字 | 關鍵字書編輯頁的「基礎」分頁 |
| 關鍵字書的快捷指令與翻譯 | 關鍵字書編輯頁的「快捷指令」分頁 |
| 骰子預設 | 「創作 → 骰子」列表頁 |

面板會依目前所在的頁面自動切換成對應的功能。

## 安裝

1. 瀏覽器先安裝 [Tampermonkey](https://www.tampermonkey.net/) 擴充功能。
2. 點下面的連結，Tampermonkey 會跳出安裝畫面，按「安裝」。

   **[→ 安裝 Caveduck編輯器](https://raw.githubusercontent.com/oliviajwart-ship-it/caveduck-widget-import/main/dist/caveduck-widget-import.user.js)**

3. 打開上表任何一頁，右下角會出現一顆圓形按鈕，點一下就展開面板。沒出現的話按 F5 重新整理。

### 更新

- Tampermonkey 預設每天檢查一次，有新版就會更新，不用重新安裝。
- 想馬上更新：打開 Tampermonkey 管理面板，在已安裝腳本清單點這支腳本的「上次更新」欄位。

## 面板的基本操作

| 位置 | 作用 |
|---|---|
| 右下角圓形按鈕 | 展開面板 |
| 面板右上角的按鈕 | 收合回圓形按鈕 |
| 標題列 | 按住可以拖曳面板 |
| 標題旁的 ⓘ | 展開這個面板的簡短說明 |
| 預覽 | 只顯示貼上的內容會被讀成幾列，不會動到網站 |
| 匯入 | 把文字框的內容填進網站 |
| 匯出到剪貼簿 | 把網站上現有的內容變成表格，複製到剪貼簿並放進文字框 |
| 清空 | 清掉文字框（小工具、快捷指令、骰子的面板才有） |

按鈕下方的訊息區會顯示每一步的結果，以及需要你留意的事。

## 貼上的內容怎麼準備

1. 在 Google Sheet 把資料照各節說明的欄位排好。
2. 選取要匯入的儲存格，複製。
3. 貼進面板的文字框，先按「預覽」確認，再按「匯入」。

- 儲存格裡有換行可以直接複製，不用另外處理。
- 下面每一節的範例都可以整段複製，直接貼進面板試。
- 不確定格式時，先在網站上手動建一筆，按「匯出到剪貼簿」再貼進 Google Sheet，就是一張可以照著填的表。

## 一、小工具

使用頁面：小工具編輯頁（網址含 `/creator-widgets/` 或 `/player-widgets/`）。

### 格式：兩欄

| A 欄 | B 欄 |
|---|---|
| 狀態值 | 文字（這個狀態值的指令內容） |

不要貼標題列，第一列就會被當成第一個狀態值。

在 Google Sheet 長這樣：

| | A | B |
|---|---|---|
| 1 | 好感度 | 0～100 的整數，代表{{char}}對{{user}}的好感 |
| 2 | 目前地點 | {{char}}現在所在的地點，10 字以內 |
| 3 | 心情 | 用一個詞描述{{char}}當下的心情 |

複製後貼進面板的內容：

```text
好感度	0～100 的整數，代表{{char}}對{{user}}的好感
目前地點	{{char}}現在所在的地點，10 字以內
心情	用一個詞描述{{char}}當下的心情
```

### 其他貼法

沒有試算表時，也可以直接貼純文字：用空行分組，每組第一行是狀態值，其餘行是文字。

```text
好感度
0～100 的整數，代表{{char}}對{{user}}的好感

目前地點
{{char}}現在所在的地點，10 字以內
```

也可以貼小工具的 HTML：工具會抓出裡面的 `{{名稱}}` 當狀態值（`{{user}}`、`{{char}}` 不算，重複的只留一個），文字欄留空。

```html
<div>好感度：{{好感度}}</div>
<div>地點：{{目前地點}}</div>
```

內容裡只要有 Tab 就會當成試算表處理，用 Tab 縮排的 HTML 也一樣。按「預覽」會顯示判斷結果（來源：試算表／HTML／純文字），匯入前先看一眼。

### 匯入

1. 貼上內容。
2. 勾選「範圍」，沒勾的那一欄不會動：
   - 狀態值(含多語)：寫入狀態值，並自動打開「管理翻譯」，把各語言還空著的狀態值補上原文（已經填好的不動），完成後自動關閉。大約 25 秒。
   - 文字：寫入文字欄。
3. 按「預覽」確認列數，再按「匯入」。
4. 檢查沒問題後，按網站的「儲存」。

- 匯入是整份覆蓋：從第一列開始填，列數不夠會自動新增，多出來的會自動刪掉。
- 匯入後如果訊息區用綠字列出一些狀態值，代表它們沒有出現在「管理翻譯」裡（可能是剛新增還沒儲存，或這個狀態值本來就不列入翻譯）。
- 還沒按網站「儲存」之前，重新整理頁面就能放棄這次匯入。

### 匯出

按「匯出到剪貼簿」會照「範圍」的勾選輸出：兩個都勾是兩欄，只勾一個就只有那一欄。

## 二、小工具的管理翻譯

在小工具編輯頁按網站的「管理翻譯」，視窗底部會多出「批次貼上翻譯」區塊。視窗上方有語言頁籤，以及「狀態值」「文字」兩個分頁；下面的按鈕都只處理目前選到的分頁。

| 按鈕 | 作用 |
|---|---|
| 複製原文 | 把原文列成一欄 |
| 複製譯文 | 把目前語言已填的譯文列成一欄 |
| 複製全部 | 把所有語言的譯文做成一張表 |
| 填入本頁 | 把貼上的內容填進目前語言 |
| 填入全部 | 把貼上的表格一次填進所有語言 |
| 清空 | 清掉文字框 |

填完一樣要按網站的「儲存」才生效。

### 格式一：填入本頁，貼一欄

每行一個譯文，照畫面由上到下的順序填。

```text
Affection
Current Location
Mood
```

行數和畫面上的欄位數不一樣時，只會填前面對得上的部分，並在訊息區提醒。

### 格式二：填入本頁，貼兩欄

| A 欄 | B 欄 |
|---|---|
| 原文 | 譯文 |

照原文名稱對應，順序不用和畫面一樣。不要貼標題列。

```text
好感度	Affection
目前地點	Current Location
心情	Mood
```

對不到的名稱會列在訊息區。

### 格式三：填入全部，貼表格

第一列是標題：第一格寫「原文」，後面每一格是一種語言的名稱。第二列起，每列是一個原文和它在各語言的譯文。

| | A | B | C | D |
|---|---|---|---|---|
| 1 | 原文 | 英文 | 日文 | 韓文 |
| 2 | 好感度 | Affection | 好感度 | 호감도 |
| 3 | 目前地點 | Current Location | 現在地 | 현재 위치 |
| 4 | 心情 | Mood | 気分 | 기분 |

```text
原文	英文	日文	韓文
好感度	Affection	好感度	호감도
目前地點	Current Location	現在地	현재 위치
心情	Mood	気分	기분
```

- 語言名稱和視窗頁籤上顯示的一樣即可：韓文、英文、日文、簡體中文、西班牙文、法文、葡萄牙文、德文、阿拉伯文、俄文。
- 語言欄的順序隨意，也可以只放其中幾種。
- 空白格不會動到原本的譯文。
- 最省事的做法：先按「複製全部」，貼進 Google Sheet 補齊，再整張複製回來按「填入全部」。

## 三、關鍵字書（Lorebook）基礎關鍵字

使用頁面：關鍵字書編輯頁的「基礎」分頁（網址含 `/lore-books/edit/`）。

### 格式：兩欄

| A 欄 | B 欄 |
|---|---|
| 關鍵字（多個用 `,` 或 `\|` 分隔） | 內容 |

不要貼標題列。

| | A | B |
|---|---|---|
| 1 | 王都,首都,艾爾登 | 王國的首都，位於大陸中央，由三層城牆環繞。 |
| 2 | 魔法學院\|學院 | 建在王都北側的寄宿學校，只收有魔力資質的學生。 |
| 3 | 銀月騎士團 | 直屬王室的騎士團，團徽是銀色新月。 |

```text
王都,首都,艾爾登	王國的首都，位於大陸中央，由三層城牆環繞。
魔法學院|學院	建在王都北側的寄宿學校，只收有魔力資質的學生。
銀月騎士團	直屬王室的騎士團，團徽是銀色新月。
```

- 關鍵字本身可以有空格；全形逗號「，」也能當分隔。
- 上限：每個項目最多 50 個關鍵字、每個關鍵字 20 字、內容 400 字。超過時訊息區會提醒。
- 每個項目至少要有一個關鍵字；同一個項目裡重複的關鍵字網站不會收。

純文字貼法：用空行分組，每組第一行是關鍵字，其餘行是內容。

```text
王都,首都,艾爾登
王國的首都，位於大陸中央，由三層城牆環繞。

魔法學院|學院
建在王都北側的寄宿學校，只收有魔力資質的學生。
```

### 匯入

| 選項 | 行為 |
|---|---|
| 新增（不動現有） | 現有項目完全不碰，新項目照貼上的順序加在最後面 |
| 覆蓋現有 | 整份取代：從第一個項目往下覆蓋，不夠的自動新增；貼的比現有少時，多出來的舊項目會被刪除 |

- 切換選項時，匯入鈕會變成「新增匯入」或「覆蓋匯入」。
- 整本只有一個空白項目時，「新增」會直接填進那個空白項目。
- 按下匯入會先跳確認視窗，說明會改寫、新增、刪除幾筆。
- 匯入後只是草稿，檢查沒問題要按網站的「儲存」才生效；重新整理頁面就能放棄。
- 合計超過 100 筆時會提醒可能超過網站上限。

### 匯出

- 輸出兩欄：關鍵字（用 `,` 接起來）和內容。
- 匯出的是最後一次按「儲存」的內容，畫面上還沒儲存的修改不會匯出。
- 關鍵字本身含有 `,` 或 `|` 時會提醒，因為重新匯入會被拆成多個。

### 排序

1. 按面板的「排序」，會列出已儲存的項目。畫面上有還沒儲存的修改時，會請你先儲存。
2. 拖曳調整順序。列前的編號是原本的位置，拖曳時不會變。
3. 按「套用順序」，確認後再按網站的「儲存」。

網站自己的「編輯順序」功能也可以照常使用。

### 編號與筆數

- 每個項目左上角的號碼是工具加上的流水號，只是顯示用，不會存進網站。
- 標題右側和面板上會顯示「畫面 N 筆｜已儲存 M 筆」。
- 按網站「儲存」後的幾秒內會顯示「存檔中…」，完成後自動恢復。

## 四、快捷指令

使用頁面：關鍵字書編輯頁的「快捷指令」分頁。切換分頁時面板會跟著換，文字框裡的內容會保留。

### 格式：三欄

| A 欄 | B 欄 | C 欄 |
|---|---|---|
| 名稱（最多 20 字） | 說明（最多 30 字） | 提示詞（最多 400 字） |

第一列如果是標題（A 欄寫「名稱」）會自動略過，貼不貼都可以。

| | A | B | C |
|---|---|---|---|
| 1 | 名稱 | 說明 | 提示詞 |
| 2 | 查看狀態 | 列出目前所有狀態 | 請用條列方式整理目前的時間、地點與每個角色的狀態，不要推進劇情。 |
| 3 | 跳到隔天 | 時間快轉到隔天早上 | 將時間推進到隔天早上，用兩三句話交代夜裡發生的事，再接續劇情。 |

```text
名稱	說明	提示詞
查看狀態	列出目前所有狀態	請用條列方式整理目前的時間、地點與每個角色的狀態，不要推進劇情。
跳到隔天	時間快轉到隔天早上	將時間推進到隔天早上，用兩三句話交代夜裡發生的事，再接續劇情。
```

- 空白格代表不動網站上現有的值。
- 超過字數上限時訊息區會提醒，網站也會拒絕儲存。
- 純文字貼法：用空行分組，每組第一行是名稱，其餘行是提示詞（說明不會填）。

### 格式：含翻譯（最多 33 欄）

前三欄之後，每種語言各佔三欄（名稱、說明、提示詞），語言順序固定如下。

| 欄 | 內容 |
|---|---|
| A～C | 原文的名稱、說明、提示詞 |
| D～F | 韓文 |
| G～I | 英文 |
| J～L | 日文 |
| M～O | 簡體中文 |
| P～R | 西班牙文 |
| S～U | 法文 |
| V～X | 葡萄牙文 |
| Y～AA | 德文 |
| AB～AD | 阿拉伯文 |
| AE～AG | 俄文 |

完整的標題列，貼進 Google Sheet 的第一列就能開始填：

```text
名稱	說明	提示詞	韓文名稱	韓文說明	韓文提示詞	英文名稱	英文說明	英文提示詞	日文名稱	日文說明	日文提示詞	簡體中文名稱	簡體中文說明	簡體中文提示詞	西班牙文名稱	西班牙文說明	西班牙文提示詞	法文名稱	法文說明	法文提示詞	葡萄牙文名稱	葡萄牙文說明	葡萄牙文提示詞	德文名稱	德文說明	德文提示詞	阿拉伯文名稱	阿拉伯文說明	阿拉伯文提示詞	俄文名稱	俄文說明	俄文提示詞
```

範例：只填英文和日文，韓文留空，日文之後的欄位不貼。

```text
名稱	說明	提示詞	韓文名稱	韓文說明	韓文提示詞	英文名稱	英文說明	英文提示詞	日文名稱	日文說明	日文提示詞
查看狀態	列出目前所有狀態	請用條列方式整理目前的時間、地點與每個角色的狀態，不要推進劇情。				Check Status	List all current status	Summarize the current time, location and each character's status as a list. Do not advance the story.	ステータス確認	現在の状態を一覧表示	現在の時間・場所・各キャラクターの状態を箇条書きでまとめてください。物語は進めないでください。
```

- 後面的語言可以不貼，沒貼到的語言不會動；排在中間的語言不填時要留空欄，不能直接跳過。
- 空白格不會動到原本的譯文。

帶翻譯的列，匯入時會多做這些事：

1. 先填好原文，並替你按一次網站的「儲存」（翻譯只能填在已儲存的指令上）。
2. 自動打開「管理翻譯」，在有填譯文的語言把該指令勾成「不參與翻譯」，再填入譯文。
3. 填完自動關閉視窗。最後還要你自己再按一次網站的「儲存」。

這本關鍵字書還沒儲存過（網址結尾是 `new`）時只會填原文。請先儲存，再匯入一次來填翻譯。

### 匯入

「新增（不動現有）」與「覆蓋現有」的行為和基礎關鍵字相同：新增會加在最後面；覆蓋是整份取代，貼的比現有少時，多出來的舊指令會被刪除。整本只有一條空白指令時，「新增」會直接填進去。匯入後按網站的「儲存」才生效。

### 匯出

輸出最後一次「儲存」的內容，共 33 欄，第一列是標題，沒有譯文的格子留白。

## 五、骰子預設

使用頁面：「創作 → 骰子」列表頁（網址結尾是 `/creates/dices`）。單顆骰子的編輯頁沒有面板。

> 這一頁沒有「儲存」鈕。按「匯入」並確認後，內容會直接寫進網站。

### 格式：含標題列的表格

第一列一定要是欄位名稱。工具靠名稱認欄位，所以欄位的順序不限。

| 欄位名稱 | 內容 | 規則 |
|---|---|---|
| id | 網站的骰子編號 | 可以整欄不要。留空時先用名稱找現有的骰子，找不到就新增 |
| 名稱 | 骰子預設的名稱 | 必填，1～100 字 |
| 骰子類型 | 1D6、2D6、3D6、1D20、1D100 | 必填，只有這五種 |
| 觸發方式 | 條件判定 或 每隔N輪 | 必填 |
| 每隔N輪 | 1、2、3、5、10、20、30、50、100 | 留空會沿用原值，新增時是 1 |
| 擲骰條件 | 文字 | 最多 200 字；觸發方式是條件判定時必填 |
| 各結果指示 | 文字，可以多行 | 必填，1～200 字，換行也算一字 |
| 公開 | 是 或 否 | 留空會沿用原值，新增時是否 |

新增兩顆骰子的範例（沒有 id 欄）：

| | A | B | C | D | E | F | G |

「各結果指示」那格有換行，從 Google Sheet 複製出來會自動用引號包住，這是正常的，直接貼就可以。

要修改現有的骰子：先按「匯出到剪貼簿」，貼進 Google Sheet（第一欄會是 id），改完把整張表複製回來匯入。

### 匯入

1. 把整張表（含標題列）貼進文字框，按「預覽」。每一列會標成：新增、更新（會列出哪幾欄變了）、不變、錯誤（會說哪裡不對）。
2. 視需要調整選項：
   - 套用貼上的順序（預設勾選）：照貼上的列序重新排列，沒貼到的骰子接在最後。
   - 刪除清單外的骰子（預設不勾）：沒貼到的骰子會被刪除，刪了無法復原。
3. 按「匯入」，在確認視窗按確定。
4. 寫入後工具會重新讀一次網站上的資料逐列核對，有不一致會列出來。
5. 按訊息區的「重新整理頁面看結果」。網站會在背景重新整理結果判定與翻譯，大約幾十秒。

### 注意事項

- 只要有一列是錯誤，整批都不會執行，修好再貼一次。
- 內容沒變的列不會重送。
- 網站每分鐘只接受 5 次新增或更新。工具會自己等待，一次改很多顆要等幾分鐘；確認視窗會先預估時間，等待中不要關掉頁面。
- 有任何一列沒寫成功時，這次不會刪除清單外的骰子，也不會重排。修好後再匯入一次，已經成功的列會顯示「不變」。
- 現有清單裡有兩顆同名的骰子時，要在 id 欄填 id 才分得出來。
- id 和名稱對不上時（id 指到的骰子叫別的名字，而這個名稱又已經是另一顆），預覽會標成錯誤。複製時請確認 id 和名稱在同一列。

### 匯出

把這一頁所有骰子輸出成 8 欄的表格，第一列是欄位名稱。

## 常見問題

### 右下角沒有出現圓形按鈕

- 按 F5 重新整理頁面。
- 確認 Tampermonkey 裡這支腳本是啟用的。
- 確認目前在最上面表格列出的頁面。

### 匯入後重新整理，內容不見了

小工具、基礎關鍵字、快捷指令匯入後都只是草稿，要按網站的「儲存」才會留下來。

### 按了匯出，卻貼不出內容

匯出的內容同時會放在面板的文字框裡。點進文字框按 Ctrl+A 全選，再按 Ctrl+C 複製。

### 貼上的內容被讀錯

按「預覽」看訊息區怎麼讀。內容裡只要有 Tab 就會當成試算表的格式。
