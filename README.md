# Caveduck編輯器

Tampermonkey 使用者腳本：在 caveduck.io 的編輯頁右下角開一個面板，把 Google Sheet 的兩欄內容
一鍵**匯入**欄位，也能把目前頁面**匯出**成可貼回試算表的格式。一支腳本同時支援小工具與 Lorebook，
依網址自動切換面板。

> **現行版本：`caveduck-widget-import.user.js`（v1.1）**——已對應 caveduck.io 2026-08 lorebook改版。
> 作者 [@lyre273](https://lyre-projects.pages.dev/)。

---

## 安裝

1. 瀏覽器先裝 **[Tampermonkey](https://www.tampermonkey.net/)** 擴充。
2. 點下面這個連結，Tampermonkey 會直接跳出安裝畫面 → 按「安裝」：

   **[→ 安裝 Caveduck編輯器](https://raw.githubusercontent.com/oliviajwart-ship-it/caveduck-widget-import/main/dist/caveduck-widget-import.user.js)**

3. 打開任一編輯頁，右下角會出現面板（沒出現就在該頁按一次 **F5**；SPA 換頁需重載一次才會注入）。

### 自動更新

腳本內建 `@updateURL`，指向這個 repo 的檔案，所以：

- **自動**：Tampermonkey 預設**每天**回來檢查一次，有新版會跳出更新提示，按確認就換好了，
  不必重貼、不必重裝。檢查頻率可在 Tampermonkey 設定裡調整。
- **手動**：Tampermonkey 管理面板 →「已安裝腳本」清單裡這支腳本的「上次更新」欄位，
  點一下就會立刻去檢查。

支援的頁面：

- 小工具：`/creator-widgets/...`、`/player-widgets/...`
- Lorebook：`/lore-books/edit/...`

面板可拖曳；右上角的鈕會把它收合成一顆圓形 icon，點一下再展開。

## 一、貼上格式（三種，自動偵測）

| 來源 | 怎麼判斷 | A 欄／第一行 | B 欄／其餘行 |
|---|---|---|---|
| 試算表 TSV | 內容含 Tab（從 Sheet 複製兩欄就會有） | 狀態值／關鍵字（Lorebook 多個關鍵字用「,」或「\|」分隔） | 文字／內容 |
| 純文字 | 空行分組 | 第一行 | 其餘行 |
| HTML（只有小工具） | 看起來像 HTML | 抓出 `{{變數}}` 當狀態值 | 空 |

- 優先序：有 Tab 一律當試算表 → 其次 HTML → 最後純文字。所以儲存格裡含 `<div>` 也不會被誤判成 HTML。
- TSV 解析支援 Google Sheets 的「引號包住的多行儲存格」與 `""` 跳脫。

## 二、小工具

- **匯入＝全部覆蓋**現有欄位：列數不夠自動點「新增資訊」補齊，多出來的自動刪掉。
- 「範圍」勾選決定要寫哪一欄，沒勾的欄位不動：
  - **狀態值(含多語)**（預設勾）＝寫狀態值欄位，並自動開「管理翻譯」，把**各語言**的狀態值空白補上原文
    （已翻好的一律不動），跑完自動關視窗。約 25 秒。
  - **文字** ＝寫指令／文字欄位。
- 匯入後如果有狀態值**沒有出現在管理翻譯**，狀態欄會用粗體綠色把它們**完整列出來**。
  原因不只一種（剛新增還沒按「儲存」、或這個狀態值本來就不列入翻譯），工具只負責告訴你是哪幾個。
- **匯出到剪貼簿**：把現有欄位輸出成 TSV，可直接貼回 Google Sheet。
- 小工具編輯器**要按網站的「儲存」才生效**，按之前可以重載丟棄，相對安全。

## 三、翻譯（管理翻譯視窗內的批次貼上）

開啟網站的「管理翻譯」後，視窗底部會自己長出一塊貼上框：

- **貼一欄**（每行一個值）＝由上到下依畫面順序填。
- **貼兩欄**（A＝原文、B＝譯文）＝依名稱對應，對不到的會列出來。
- 只填**目前語言／目前分頁**，log 會標明來源，例如「已填入 英文／文字：3 筆」。
- `複製原文`＝把本頁原文列成一欄；`複製譯文`＝把本頁目前已填的譯文列成一欄。
  兩者都會把結果塞進框裡，並嘗試複製到剪貼簿。
- 改完一樣要按網站「儲存」。
- 想一次補滿各語言的狀態值，用小工具面板的「狀態值(含多語)」勾選（見上面第二節）。

## 四、Lorebook

### 項目編號與統計（自動）

- 每個項目左上角會加上**流水號徽章**（純顯示，不會存進網站），新增／刪除／排序後自動跟著變。
- 「基礎關鍵字」標題右側與面板上會顯示「**畫面 N 筆｜已儲存 M 筆**」。
- 按網站「儲存」後伺服器要幾秒才反映，筆數有變的話這段期間會顯示「**存檔中…**」，追上後自動恢復。

### 關鍵字格式

- 一個項目可以有多個關鍵字：A 欄用「,」或「|」分隔（**關鍵字本身可以含空格**）。
- 匯出時關鍵字之間用「,」接回；關鍵字本身含「,」或「|」時會警告（重新匯入會被拆開）。
- 上限：每項關鍵字最多 50 個、每個 20 字；內容 400 字。

### 兩種匯入方式

| 模式 | 行為 |
|---|---|
| **新增（不動現有）** | 現有項目完全不碰，新項目照貼上順序加在清單**最後面**。 |
| **覆蓋現有** | 整份取代：從第一列往下覆蓋；不夠再新增；**貼的比現有少時，多出來的舊項目會被刪除**。 |

兩種都會先跳確認視窗說明將發生什麼事；執行中會鎖住按鈕，完成後記得按網站「儲存」。

### 拖曳排序

按面板的「排序」→ 列出目前**已儲存**的項目（畫面上有未儲存變更會先請你儲存）→
拖曳調整 → 「套用順序」。

- 列前的編號＝該項**原本的位置**：拖曳後不會變，套用並儲存後、下次打開才會是新編號。
- 「排序」實際上是把內容重寫回固定位置；沒動的列會自動跳過。網站原生的「編輯順序」也可以用。
- 匯出走網站後端資料（最後一次儲存的內容），畫面上未儲存的草稿不會被匯出。

## 共用操作

- **預覽**：先看會切成幾組，不會動到頁面。
- **匯入**：實際填入欄位。
- **匯出到剪貼簿**：輸出成 TSV，可直接貼回 Google Sheet。
- **確認框**會蓋在編輯區正中央，不會跑到視窗最上方。
- **狀態欄**：完成訊息粗體紅字；需要你注意的清單（例如沒出現在管理翻譯的狀態值）粗體綠字完整列出。
